# 🖥 PC Control Bot

Telegram бот для керування своїм ПК прямо з телефону.  
Кожен користувач підключає **свій** комп'ютер — ніхто не має доступу до чужого.

---

## ✨ Функції

| Функція | Опис |
|---|---|
| 📊 Статистика | CPU, RAM, диск, мережа, температура, аптайм |
| 🔊 Гучність | Підкрутити, скрутити, mute |
| 🎵 Музика | Play/Pause, наступний, попередній трек |

| 🔴 Вимкнення | Вимкнути або перезавантажити ПК |

## 🚀 Як запустити бота (Railway / сервер)

### 1. Клонуй репозиторій
```bash
git clone https://github.com/ТВІ_ЮЗЕРНЕЙМ/pc-control-bot.git
cd pc-control-bot
```

### 2. Встанови залежності
```bash
pip install -r requirements.txt
```

### 3. Створи файл `.env`
```
BOT_TOKEN=твій_токен_від_BotFather
```

### 4. Запусти
```bash
python main.py
```

> Для продакшену рекомендується деплой на [Railway](https://railway.app)

---

## 💻 Як підключити свій ПК до бота

1. Напиши боту `/start`
2. Натисни **🖥 Комп'ютер** → **🔌 Підключити ПК**
3. Отримай унікальний код підключення
4. Завантаж `pc_agent.py` на свій ПК
5. Встанови бібліотеки:
```bash
pip install aiogram psutil pycaw comtypes Pillow pyautogui
```
6. Відкрий `pc_agent.py` і встав токен бота
7. Запусти:
```bash
python pc_agent.py
```
8. Введи свій код — ПК з'явиться онлайн! ✅

> ⚠️ `pc_agent.py` має бути запущений на ПК поки ти хочеш ним керувати.
